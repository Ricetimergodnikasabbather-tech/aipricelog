How to read these prices

AI APIs charge per token. A token is about ¾ of a word, so 1 million tokens is roughly 750,000 words. Input is the text you send (your prompt, documents, chat history). Output is the text the model writes back, and it usually costs 4–8 times more. Cached input is the discounted rate when you resend the same long prompt, which matters for chatbots and agents.

The calculator multiplies your token counts by each model's standard rate. Batch processing, long-context surcharges and regional pricing can change the real bill; each model page lists those rates where providers publish them.

Prices are per 1 million tokens in US dollars, standard API rates. Data from the open LiteLLM price database, checked daily (last check 2026-10-16 15:18 UTC). Always confirm on the provider's pricing page before you commit.
